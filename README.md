# Tooling ATR Maven Example

This is an example project issued by Tooling at the ASF. It contains no user facing functionality.
We do not make guarantees about any of its content, nor the continued existence of this project.

It is a proof of concept of [ATR Trusted Publishing](https://releases.apache.org/docs/trusted-publishing)
for projects built with Maven, see [apache/tooling-trusted-releases#1844](https://github.com/apache/tooling-trusted-releases/issues/1844).
The release runs in GitHub Actions with the standard Maven release process,
as described in [Publishing Maven Artifacts](https://infra.apache.org/publishing-maven-artifacts.html).
